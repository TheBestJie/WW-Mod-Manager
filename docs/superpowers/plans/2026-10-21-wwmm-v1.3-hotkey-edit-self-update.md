# WWMM V1.3（快捷键修改 + 自动检查更新）实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 subagent-driven-development（推荐）或 executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 快捷键查看界面支持选中行按 `R` 进入编辑屏重新绑定（写回 ini），启动时自动对比 GitHub releases 与本地版本号，`Ctrl+U` 触发检查并自更新（`git pull`）。

**架构：** 两个互不相关的子系统。快捷键链：`hotkeys.py` 的 `Hotkey` 增加定位字段（原始值 / key|back / 同段内序号），新增无 Textual 依赖的 `hotkey_edit.py` 负责校验（只认 3Dmigoto/WWMI 语法）与原子写回；`HotkeysScreen` 从分组 `Static` 表格改为 `OptionList` 可选行（分组头做 separator），新增 `HotkeyEditScreen` 模态编辑屏。更新链：新增无 Textual 依赖的 `self_update.py`（urllib 拉 GitHub releases API、版本号比较、检测仓库根、`git pull` 自更新），`WWMMApp` 注入 `release_checker`/`self_updater`（仿照现有 `updater`/`detector` 注入模式），`SelfUpdateScreen` 模态屏 + App 级 `Ctrl+U` 绑定，`HomeScreen.on_mount` 起后台线程静默检查。

**技术栈：** Python ≥ 3.11、Textual 8.x、Rich、urllib（标准库，不引入第三方依赖）、subprocess（git/uv）、pytest / pytest-asyncio、ruff。

**规格：** 本计划无独立规格文档（用户跳过了头脑风暴）。需求原文（用户消息 m00001）：

> 1、在Mod的快捷键查看界面支持修改选中的快捷键。选中需要修改的快捷键按R键进入快捷键编辑界面，可以重新绑定新的快捷键，也可以取消快捷键修改。
> 2、添加自动检查更新，根据github中的releases版本号与本地版本号对比实现。如果本地不是最新版本则提示更新。Ctrl + U 进行自动更新。
> 快捷键需要为XXMI支持的快捷键组合。

键位语法依据 3Dmigoto 官方 `vkeys.h` / `d3dx.ini`（与 V1.1 规格一致），即「XXMI 支持的快捷键组合」。

## 全局约束

- 写回 ini 必须原子（临时文件 + `os.replace`），保留 BOM、注释、空行、其他 section 和同段其他 `key`/`back` 行，只替换目标行。
- 键位校验只认 3Dmigoto 语法：单字符、`_VK_LABELS` 中的名称（可省略 `VK_` 前缀）、`0x` 十六进制码、`XB_` 手柄键、`no_` 排除前缀；不支持的组合必须拒绝并给出中文错误。
- `wwmm/hotkey_edit.py` 与 `wwmm/self_update.py` 不得 import Textual；UI 与逻辑分离。
- 自更新不引入第三方依赖：urllib 拉取 `https://api.github.com/repos/TheBestJie/WW-Mod-Manager/releases/latest`；更新动作用 `git -C <repo> pull --ff-only`，`uv` 存在时追加 `uv tool install --editable --force <repo>`。
- 启动自动检查的网络失败必须静默（仅 log.debug），不得弹错误通知、不得阻塞 TUI；`Ctrl+U` 手动检查的失败要显示可理解的错误。
- 非可更新安装（找不到 git 仓库根 / 非 editable 安装）时给出手动更新 URL 提示，不得执行 git 命令。
- 所有测试 hermetic：网络用 monkeypatch 假 `urlopen`，git/uv 用假 runner 或 tmp 仓库；禁止真实网络访问。
- TUI 文案中文；代码标识符、文件名、commit message 英文；`ruff` line-length 100。
- 版本号 `1.2.0` → `1.3.0`，同步 `pyproject.toml`、`src/wwmm/__init__.py`、`tests/test_cli.py`。
- 新异常类型加入 `src/wwmm/errors.py`：`HotkeyEditError(WWMMError)`、`SelfUpdateError(WWMMError)`。

## 审查重点（Review Focus）

1. **写回不得破坏 ini 其他内容**：BOM、`;` 注释、同段第二条 `Key` 行、`[TextureOverride...]` 等无关 section 都必须原样保留。测试在任务 1 的 `test_apply_preserves_bom_comments_and_sibling_lines`。
2. **同段多条 `key`/`back` 行的定位**：改第 2 条 `key` 不得动第 1 条；改 `back` 不得动 `key`。测试在任务 1 的 `test_apply_targets_exact_occurrence`。
3. **非法键位组合必须拒绝**：中文输入、乱码 token、空输入不能进 ini。测试在任务 1 的 `test_validate_rejects_unsupported`。
4. **启动自动检查的网络失败必须静默且不阻塞**：checker 抛异常时主页照常可用，无错误弹窗。测试在任务 6 的 `test_startup_check_failure_is_silent`。
5. **无网络 / 无 release / 非可更新安装时 `Ctrl+U` 不崩溃**：显示可理解的中文错误或手动更新 URL。测试在任务 4 的 `test_fetch_raises_on_missing_release`、`test_find_repo_root_requires_git_clone` 和任务 5 的 `test_check_error_shows_message`。

def apply_hotkey(mod_path: Path, source: str, section: str,

读 `mod_path / source` 的 bytes，`decode("utf-8-sig", errors="surrogateescape")`；逐行扫（复用 `_SECTION_RE` 跟踪当前段，段名 casefold 匹配），行内用 `_FIELD_RE` 匹配 `field`（casefold 相等）时递增计数器，命中 `occurrence` 后整行替换为 `f"{field 行前缀原文} = {new_raw}"`（保留原行 `key`/`back` 拼写与 `=` 前空白格式：用 `re.sub(r"^(\s*key\s*=\s*).*$", …, count=1, flags=IGNORECASE)` 按行替换）；未命中 → 抛 `HotkeyEditError`。写回：`encode("utf-8-sig", errors="surrogateescape")` 写 `<file>.tmp` 后 `os.replace`（BOM：utf-8-sig 编码自动恢复）。

```python

RELEASES_PAGE_URL = "https://github.com/TheBestJie/WW-Mod-Manager/releases/latest"

@dataclass(frozen=True)

    current: str
    latest: ReleaseInfo

@dataclass(frozen=True)
class SelfUpdateResult:
    new_version: str
    reinstalled: bool

def parse_version(text: str) -> tuple[int, ...]
def fetch_latest_release(url: str = RELEASES_API_URL, timeout: float = 15) -> ReleaseInfo
def check_for_update(current: str = __version__, url: str = RELEASES_API_URL, timeout: float = 15) -> UpdateCheck | None
def find_repo_root(start: Path | None = None) -> Path
def perform_self_update(repo_root: Path, runner=subprocess.run) -> SelfUpdateResult
```

- `parse_version`：去 `v` 前缀、按 `.` 切、每段 `int()`（失败抛 `SelfUpdateError(f"无效版本号：{text}")`），返回 int 元组。
- `fetch_latest_release`：`Request(url, headers={"User-Agent": USER_AGENT})` + `urlopen`；OSError → `SelfUpdateError(f"获取 GitHub release 失败：{exc}")`；JSON 解析失败/缺 `tag_name` → `SelfUpdateError("GitHub release 响应格式无效")`；`tag_name.lstrip("v")` 得 version，`url = data.get("html_url", RELEASES_PAGE_URL)`。
- `check_for_update`：`parse_version(latest) > parse_version(current)` 才返回 `UpdateCheck`，否则 None（元组比较天然处理 `1.3` vs `1.3.0`）。
- `find_repo_root`：从 `start or Path(__file__).resolve()` 逐级向上找含 `pyproject.toml` 且 `tomllib` 解析出 `project.name == "ww-mod-manager"` 的目录；再要求 `.git` 目录存在；否则 `SelfUpdateError(f"未找到可自动更新的 git 仓库（需要 git clone + install.sh 安装），请手动更新：{RELEASES_PAGE_URL}")`。
- `perform_self_update`：`runner(["git", "-C", str(repo_root), "pull", "--ff-only"], capture_output=True, text=True, check=False)`；returncode != 0 → `SelfUpdateError(f"git pull 失败：{stdout+stderr 摘要}")`；`shutil.which("uv")` 存在则跑 `uv tool install --editable --force <repo_root>`（失败仅 `log.warning`，不中断）；从新 `pyproject.toml` 读 `project.version` 返回 `SelfUpdateResult`。
