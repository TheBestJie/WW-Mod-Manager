# WWMM V1.1（mod 快捷键查询）实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 subagent-driven-development（推荐）或 executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 在 mod 列表选中 mod 按 `m`，弹出按类型分组的 ini 快捷键列表，禁用 mod 有提示，50+ 条可滚动。

**架构：** 新增纯文件解析模块 `hotkeys.py`（不依赖 Textual），按 3Dmigoto 官方 `[Key...]` 语法支持多 `Key`/`Back`、`VK_` 可选、十六进制码和 Xbox 手柄键；新增 `HotkeysScreen` 模态屏负责分组渲染。`ModsScreen` 只增加 `m` 绑定和按需调用，不改 scanner / `Mod` 模型。

**技术栈：** Python ≥ 3.11、Textual 8.2、Rich、pytest / pytest-asyncio、ruff；语法依据 3Dmigoto 官方 `d3dx.ini` / `vkeys.h`。

**规格：** `docs/superpowers/specs/2026-10-20-wwmm-v1.1-hotkeys-design.md`

## 全局约束

- 只读 ini；不修改、不移动、不写回任何 mod 文件。
- 按键语法以 3Dmigoto 官方 `Dependencies/d3dx.ini` 与 `vkeys.h` 为准，不按本地样本裁剪；本地 mod 只用于验收。
- 跳过隐藏目录/文件和 `DISABLED*` 目录/文件（大小写不敏感），与 `d3dx.ini` 的 `exclude_recursive = DISABLED*` 一致。
- `wwmm/hotkeys.py` 不得 import Textual；UI 与解析分离。
- TUI 文案用中文；代码标识符、文件名、commit message 用英文。
- 所有测试只用 `tmp_path`/临时目录；禁止把测试指向真实 Mods 路径。
- 保持现有代码风格；`ruff` line-length 100。
- 版本号从 `0.1.0` 升到 `1.1.0`，同步 `pyproject.toml`、`src/wwmm/__init__.py`、`tests/test_cli.py`。

## 审查重点（Review Focus）

1. **同一段多条 `Key`/`Back` 行**：不能 last-wins 覆盖，否则会漏掉键盘/手柄/反向键。测试在任务 1 的 `test_parses_multiple_keys_and_back`。
2. **`VK_` 省略、十六进制、Xbox 键名**：`RBUTTON`、`0x70`、`XB2_LEFT_TRIGGER` 都必须解析成可读按键，不能漏。测试在任务 1 的 `test_format_key`。
3. **`key = ;` 是合法按键**：不能被当成注释整行跳过。测试在任务 1 的 `test_semicolon_key_is_not_a_comment`。
4. **嵌套 `DISABLED_*`**：启用 mod 内部的 `DISABLED_*` 子目录/ini 在游戏里不生效，不能出现在列表中。测试在任务 1 的 `test_skips_hidden_and_disabled_ini`。
5. **禁用 mod**：仍要显示按键，但必须同时显示「不会生效」的警告。测试在任务 3 的 `test_m_warns_for_disabled_mod`。

- [ ] **步骤 3：在 `src/wwmm/hotkeys.py` 中实现解析**

定义以下公开接口：

```python
class HotkeyKind(str, Enum):
    SWITCH = "切换"
    HOLD = "长按"
    OTHER = "其他"


@dataclass(frozen=True)
class Hotkey:
    display_key: str
    section: str
    source: str
    kind: HotkeyKind
    back: bool = False


def format_key(raw: str) -> str: ...


def parse_mod_hotkeys(mod_path: Path) -> list[Hotkey]: ...
```

实现要点：

- 用 `os.walk(mod_path, followlinks=False)` 收集 `.ini`；在遍历时过滤 `dirnames[:]` 和 `filenames`：以 `.` 开头或以 `DISABLED` 开头（`casefold()` 后判断）的目录/文件跳过。收集后按相对路径 `as_posix().casefold()` 排序，保证跨平台稳定顺序。
- 逐行解析，正则固定为：
  - 段头：`^\s*\[([^\]]+)\]\s*$`
  - 字段：`^\s*(key|back|type)\s*=\s*(.*?)\s*$`，`re.IGNORECASE`
- 行扫描时先跳过空行和首个非空白字符为 `;`/`#` 的行；遇到新段先 flush 上一段，文件结束再 flush。
- flush 只处理段名 `casefold().startswith("key")` 的段；段内维护 `raw_keys: list[str]`、`raw_backs: list[str]`、`type_value: str`，**每条 `key`/`back` 都保留**，不能 last-wins。
- 对每条 `raw_keys` 生成 `Hotkey(..., back=False)`，对每条 `raw_backs` 生成 `Hotkey(..., back=True)`；`format_key` 返回空串时跳过该条。`type` 取最后一次出现的值，缺失按空串处理。
- `type` 分类：`cycle`/`toggle` → `HotkeyKind.SWITCH`；`hold` → `HotkeyKind.HOLD`；其余 → `HotkeyKind.OTHER`。
- 单个 ini 读取失败时 `log.warning` 并跳过，不影响其余文件；读取用 `encoding="utf-8-sig", errors="ignore"` 兼容 BOM；`mod_path` 不是目录时直接返回 `[]`。
- `source` 用 `ini.relative_to(mod_path).as_posix()`。
- `format_key`：
  - 按空白切分；任意 `NO_` 开头的 token（含 `NO_MODIFIERS`、`NO_VK_DECIMAL`）丢弃；剩余每个 token 都映射为可读标签，最后用 `+` 连接（3Dmigoto 的组合键是这些键同时按住，不区分“修饰键/主键”）。
  - A-Z / 0-9 单字符转大写；其他单字符（`;`、`/`、`[` 等）原样保留。
  - `0xNN` 十六进制码转整数，再查虚拟键码反查表（由 `vkeys.h` 的 code 建表）；未识别时显示 `0xNN`。
  - Xbox 手柄键用 `^XB([1-4])?_(.+)$` 识别，映射 `A/B/X/Y/START/BACK/GUIDE`、`DPAD_UP/DOWN/LEFT/RIGHT`、`LEFT/RIGHT_TRIGGER`→`LT/RT`、`LEFT/RIGHT_SHOULDER`→`LB/RB`、`LEFT/RIGHT_THUMB`→`LS/RS`；有手柄号时显示 `手柄2 X`，否则 `手柄 X`。
  - 其他键名去掉可选的 `VK_` 前缀、转大写后查 `VK_LABELS`。`VK_LABELS` 按 3Dmigoto `vkeys.h` 的 `VKMappings` 单 token 键名建表（不裁剪；带空格的遗留别名如 `Num 1`、`Prnt Scrn` 不在此范围），并补可读别名：鼠标键 → `左键/右键/中键/侧键1/侧键2`、方向键 → `↑↓←→`、`NUMPAD0..9` → `小键盘 n`、`DECIMAL` → `小键盘 .`、`DIVIDE/MULTIPLY/SUBTRACT/ADD` → `小键盘 / * - +`、`F1..F24` → `F1..F24`、OEM 标点 → 对应 US 布局符号（`;`、`/`、反引号、`[`、`\`、`]`、`'`、`,`、`-`、`.`、`=`）、`CONTROL/CTRL` → `Ctrl`、`MENU/ALT` → `Alt`、`RETURN/ENTER` → `Enter`、`PRIOR/PGUP` → `PgUp`、`NEXT/PGDN` → `PgDn` 等。
  - 未识别的键名保留去掉 `VK_` 后的原名（如 `OEM_102`），不丢行。
  - 输出 `"+".join(labels)`；没有标签时返回空串。
- `back` 只影响显示标记，不影响分类；即使出现在非 cycle 段也照常显示。

公开接口：

```python
class HotkeysScreen(ModalScreen[None]):
    BINDINGS: ClassVar[list[Binding]] = [
        Binding("escape", "close", "关闭"),
        Binding("m", "close", "关闭"),
    ]

    def __init__(self, mod: Mod, hotkeys: list[Hotkey]) -> None: ...

    @property
    def grouped(self) -> list[tuple[HotkeyKind, list[Hotkey]]]: ...
```

实现要点：

- `__init__` 保存 `self.mod = mod`、`self.hotkeys = list(hotkeys)`。
- 需要 `from rich.table import Table`、`from rich.text import Text`、`from textual.containers import Vertical, VerticalScroll`、`from textual.screen import ModalScreen`、`from textual.widgets import Static`。
- `compose` 结构：`Vertical(id="hotkeys-box")` 内依次是
  `Static(self._header(), id="hotkeys-header")`、
  禁用时 `Static(Text("该 mod 已禁用，以下快捷键在游戏中不会生效。", style="yellow"), id="hotkey-warning")`、
  `VerticalScroll(id="hotkeys-scroll")`、`Static(..., id="hotkeys-hint")`。
- 滚动区内：无按键时 `Static(Text(self._empty_message(), style="dim"), id="hotkey-empty")`；
  否则每个非空分组先输出 `Static(Text(f"{kind.value} · {len(rows)} 项"), id=f"hotkey-group-{kind.name.lower()}", classes="hotkey-group")`，
  再输出 `Static(self._table(rows), id=f"hotkeys-table-{kind.name.lower()}", classes="hotkey-table")`。
- `grouped` 按 `HotkeyKind` 定义顺序（SWITCH、HOLD、OTHER）分组，空组不返回。
- `_header()` 用 `Text.assemble((self.mod.display_name, "bold"), f" · {state} · {len(self.hotkeys)} 个快捷键")`；
  `state` 为 `已启用`/`已禁用`。
- `_empty_message()`：`self.mod.ini_count == 0` → `该 mod 没有 ini 文件`；否则 → `该 mod 的 ini 里没有声明 [Key...] 快捷键`。
- `_table(rows)` 用 Rich `Table(box=None, show_header=True, header_style="bold", padding=(0, 1), expand=True)`：
  - `按键`：`style="bold yellow"`、`width=14`、`no_wrap=True`
  - `功能（ini 段落）`：`ratio=3`、`no_wrap=True`、`overflow="ellipsis"`；单元格文本为
    `h.section + (" · 反向" if h.back else "")`
  - `来源`：`style="dim"`、`ratio=2`、`no_wrap=True`、`overflow="ellipsis"`
  - 单元格全部用 `Text(...)`，不要用字符串，避免 `[X]` 这类路径被当成 markup。
- `on_mount` 里 `self.query_one("#hotkeys-scroll", VerticalScroll).focus()`，让方向键/PgUp/PgDn 直接滚动。
- `action_close` 调用 `self.dismiss(None)`。
- 底部提示文案固定：`↑↓ / PgUp / PgDn 滚动 · Esc 关闭`，用 `Text(..., style="dim")`。
