# WWMM V1（Linux TUI + 角色表流水线）实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 subagent-driven-development（推荐）或 executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 在 Linux 上提供一个原生 TUI 的鸣潮 XXMI/WWMI mod 管理器：按属性分组浏览角色→mod、全局搜索、用 `DISABLED_` 前缀启停，并由 GitHub Actions 每日维护角色表。

**架构：** Python 3.11+ / Textual 8 的纯文件操作 TUI。core（constants/models/config/roster/scanner/toggle/search）与 UI 分离；角色表由 `scripts/build_roster.py` 从 Arikatsu 解包数据生成，Actions 每日提交 `data/roster.json`，app 通过 `wwmm update` 拉取。

**技术栈：** Python 3.14（开发）/ 3.12（Actions）、Textual 8.2、platformdirs、tomli-w、pypinyin、pytest / pytest-asyncio / PyYAML / ruff。

**规格：** `docs/superpowers/specs/2026-10-19-wwmm-v1-design.md`

## 全局约束

- 只支持 Linux；路径可能包含空格、中文、全角标点。
- 只重命名 mod 顶层文件夹；不删除、不移动、不改 mod 内部文件。
- 禁用前缀固定为 `DISABLED_`；只有 `character/<角色>` 的直接子文件夹是 mod。
- 所有测试只用 `tmp_path`/临时目录；禁止把测试指向真实 Mods 路径。
- 角色表 schema v1；`data/roster.json` 是规范文件，`src/wwmm/data/roster.json` 是包内置回退。
- 分组顺序固定：冷凝、热熔、导电、气动、衍射、湮灭、多属性、其他、未分类。
- 角色表更新只加目录，从不删除角色目录。
- TUI 文案用中文；代码标识符、文件名、commit message 用英文。
- 开发命令统一用已安装的 `uv`：`uv venv .venv && uv pip install -e ".[dev]"`。
- GitHub Actions 每天 03:00（北京时间，`0 19 * * *` UTC）运行；数据无变化时不下载、不提交。

## 审查重点（Review Focus）

1. **mod 名字本身以 `DISABLED_` 开头**：启用时只能去掉一个前缀，禁用时必须还原成同一个名字；不能把 `DISABLED_DISABLED_Foo` 变成 `DISABLED_Foo` 或反过来。测试放在任务 6。
2. **启用时目标已存在**：`Foo` 和 `DISABLED_Foo` 同时存在时必须中止，两个目录都保持原样。测试放在任务 6。
3. **中文/空格/超长路径**：扫描要正确显示，重命名失败要给出中文错误且不留下半完成状态。测试放在任务 5、6。
4. **上游角色表异常**：下载到空数据、缺少 `rover`/`others`、slug 重复时必须校验失败，不能覆盖旧 `data/roster.json`。测试放在任务 16、17。
5. **错误的 Mods 目录**：首次设置时如果选了一个普通目录，不能在里面创建 58 个角色文件夹；必须拒绝保存。测试放在任务 14、10。

- [ ] **步骤 4：实现 `roster.py`**

接口：

```python
class RosterError(Exception): ...


@dataclass(frozen=True)
class RosterSource:
    repo: str
    branch: str
    commit: str
    committed_at: str


@dataclass(frozen=True)
class Roster:
    schema_version: int
    game_version: str
    source: RosterSource
    characters: tuple[Character, ...]

    def by_slug(self, slug: str) -> Character | None: ...
    def by_folder(self, folder: str) -> Character | None: ...
    def groups(self) -> dict[str, list[Character]]: ...


def parse_roster(data: dict) -> Roster: ...
def load_roster_file(path: Path) -> Roster: ...
def load_bundled_roster() -> Roster: ...
def load_effective_roster(data_dir: Path) -> Roster: ...
```

`RosterError` 从 `wwmm.errors` 导入。规则：

- `schema_version` 必须为 1；`characters` 非空。
- `slug` 必须匹配 `^[a-z0-9]+$`；`folder` 默认等于 `slug`；`slug` 和 `folder` 都不能重复（大小写不敏感）。
- `name_zh`/`name_en` 非空；`elements` 必须是 `ELEMENTS` 的子集；非 `special` 角色至少一个属性。
- `others` 缺失时自动追加，`pinyin="qita"`、`initials="qt"`、`aliases=("其他", "others")`。
- `by_folder` 同时匹配 `folder`、`slug` 和 `aliases`，大小写不敏感。
- `load_bundled_roster` 读 `Path(__file__).with_name("data") / "roster.json"`。
- `load_effective_roster` 优先本地 `data_dir/"roster.json"`；本地损坏时记录 warning 并回退内置。
- `groups()` 返回所有 `GROUP_ORDER` 键；每组按 `(name_zh, slug)` 排序。

`LayoutError` 从 `wwmm.errors` 导入。规则：

- 不删除任何现有目录。
- 记录日志：创建数量、错误数量。

      - uses: actions/checkout@v4

      - uses: actions/setup-python@v5
        with:
          python-version: "3.12"

      - name: Install dependencies
        run: python -m pip install --disable-pip-version-check -e .

      - name: Generate roster
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
        run: python scripts/build_roster.py --out data/roster.json

      - name: Commit if changed
        run: |
          if git diff --quiet -- data/roster.json; then
            echo "No roster changes."
            exit 0
          fi
          VERSION=$(python -c 'import json; print(json.load(open("data/roster.json"))["game_version"])')
          git config user.name "github-actions[bot]"
          git config user.email "41898282+github-actions[bot]@users.noreply.github.com"
