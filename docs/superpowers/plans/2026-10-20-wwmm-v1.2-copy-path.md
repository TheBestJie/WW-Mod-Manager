# WWMM V1.2（快速复制路径）实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 subagent-driven-development（推荐）或 executing-plans 逐任务实现此计划。步骤使用复选框（`- [x]`）语法来跟踪进度。

**目标：** 在角色列表按 `c` 复制角色文件夹绝对路径，在 mod 列表按 `c` 复制选中 mod 文件夹绝对路径，粘贴到文件管理器地址栏即可直达。

**架构：** 新增不依赖 Textual 的 `clipboard.py`，依次尝试 `wl-copy` / `xclip` / `xsel`；`WWMMApp.copy_text()` 同时发送 OSC 52 并调用该模块，兼顾终端与桌面剪贴板。两个列表屏各加一个 `c` 绑定和 action，复制后用通知显示路径。

**技术栈：** Python ≥ 3.11、Textual 8.2、pytest / pytest-asyncio、ruff；只用标准库 `shutil` / `subprocess`。

**规格：** 本轮用户需求（2026-10-20），无独立规格文档。

## 全局约束

- TUI 文案用中文；代码标识符、文件名、commit message 用英文。
- 不新增第三方依赖。
- 复制绝对路径：不加引号、不展开/解析符号链接、不去掉 `DISABLED_` 前缀。
- 复制动作只读，不修改任何文件或目录。
- 测试只用 `tmp_path` / 临时目录；禁止访问真实 Mods 目录；屏幕测试必须屏蔽外部剪贴板命令。
- 保持现有代码风格；`ruff` line-length 100。
- 版本号从 `1.1.0` 升到 `1.2.0`，同步 `pyproject.toml`、`src/wwmm/__init__.py`、`tests/test_cli.py`。

## 审查重点（Review Focus）

1. **过滤器输入框聚焦时按 `c`**：必须作为普通字符输入过滤器，不能触发复制。测试在任务 2 的 `test_c_in_filter_does_not_copy`。
2. **禁用 mod**：复制的必须是带 `DISABLED_` 前缀的真实目录路径。测试在任务 2 的 `test_c_copies_disabled_mod_path`。
3. **中文/非 ASCII 路径**：必须原样复制，不能被转义或截断。测试在任务 2 的 `test_c_copies_selected_mod_path`。
4. **没有任何外部剪贴板工具**：`copy_with_command` 返回 `False`，不抛异常，OSC 52 仍然发送。测试在任务 1 的 `test_returns_false_when_no_tool_available`。

```python
"""Copy text through desktop clipboard commands."""

from __future__ import annotations

import shutil
import subprocess

_CANDIDATES = (
    ("wl-copy", ()),
    ("xclip", ("-selection", "clipboard")),
    ("xsel", ("--clipboard", "--input")),
)


def copy_with_command(text: str) -> bool:
    """Copy text with the first working desktop clipboard command."""
    for name, args in _CANDIDATES:
        executable = shutil.which(name)
        if executable is None:
            continue
        try:
            result = subprocess.run(
                [executable, *args],
                input=text,
                text=True,
                stdout=subprocess.DEVNULL,
                stderr=subprocess.DEVNULL,
                timeout=2,
                check=False,
            )
        except (OSError, subprocess.SubprocessError):
            continue
        if result.returncode == 0:
            return True
    return False
```

def action_copy_path(self) -> None:
    if not self._visible:
        return
    list_view = self.query_one("#characters", ListView)
    index = list_view.index or 0
    if index >= len(self._visible):
