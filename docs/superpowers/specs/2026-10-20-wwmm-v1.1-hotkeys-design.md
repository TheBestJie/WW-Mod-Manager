# WWMM V1.1 设计：mod 快捷键查询

- 日期：2026-10-20
- 状态：已与用户确认
- 关联计划：`docs/superpowers/plans/2026-10-20-wwmm-v1.1-hotkeys.md`

## 1. 背景与目标

WWMI mod 的可交互按键写在 mod 目录下 ini 的 `[Key...]` 段里（`key = ...`、`type = ...`）。
用户经常不记得某个 mod 的按键，目前只能打开文件夹翻 ini。

目标：在 mod 列表选中一个 mod，按 `m`，弹窗按类型分组列出该 mod 的所有按键；不改任何文件，
不让用户离开终端。

成功标准：按 `m` 后立即看到分组列表；50+ 条按键可滚动；禁用 mod 有明确提示；
`Esc` 回到 mod 列表。

## 2. 范围

### 包含

- 解析选中 mod 下所有会生效的 `.ini`，提取 `[Key...]` 段中的全部 `key` 与 `back` 行。
- 支持 3Dmigoto 的完整按键写法：`VK_` 前缀可有可无、十六进制虚拟键码、Xbox 手柄键、同一段多个键、cycle 反向键。
- 按 `type` 分三组：切换（cycle/toggle）、长按（hold）、其他（默认/其他 type）。
- 单列表 + 组标题，三列：按键、ini 段落名、来源文件。
- 按键转易读写法；段落名原样显示；`back` 行标注「反向」。
- 禁用提示、空状态、滚动、`Esc`/`m` 关闭。
- README 键位说明；版本 1.1.0。

### 不包含

- 修改、重绑、写回按键。
- 解析 `d3dx.ini` 或 `Core/WWMI/KeyBindings.ini` 里的全局键。
- 跟随 mod ini 里的 `[Include]` 跳到 mod 目录之外。
- `vkeys.h` 里带空格的遗留别名（`Num 1`、`Prnt Scrn`）作为组合键；3Dmigoto 自己也不建议这样用。
- 翻译段落名、按功能重命名。
- 弹窗内搜索/过滤、多选、复制到剪贴板。
- 缓存解析结果。

## 3. 数据来源与解析规则

语法依据 3Dmigoto 官方 `Dependencies/d3dx.ini` 与 `vkeys.h`（见 §7），不是只按本地 mod 样本归纳。

- 递归读取 mod 根目录下所有 `.ini`（扩展名大小写不敏感），跳过：
  - 隐藏目录/文件（`.` 开头）；
  - 任何以 `DISABLED` 开头的目录或文件（大小写不敏感），与 `d3dx.ini` 的
    `exclude_recursive = DISABLED*` 一致。
- 只处理段名以 `key` 开头的段（大小写不敏感），例如 `[KeyHair]`、`[keySwap]`。
- 段内解析（字段名大小写不敏感）：
  - `key` 与 `back` 都可以出现多次；每一条都生成一行快捷键（同一段多个键共享状态）。
  - `key`/`back` 值为空或缺失的条目忽略。
  - `type` 取最后一次出现的值；缺失表示默认单次触发。
- 注释只认整行：首个非空白字符为 `;` 或 `#` 的行跳过；`key = ;` 是合法按键。
- 分类：
  - `type = cycle` / `toggle` → 切换
  - `type = hold` → 长按
  - 默认/缺失/其他 type → 其他
- 按键写法（全部按 3Dmigoto 规则支持）：
  - A-Z / 0-9：单字符。
  - 其他键：虚拟键名，`VK_` 前缀可有可无，大小写不敏感；也支持 `0xNN` 十六进制虚拟键码。
  - 组合键：空格分隔；每个非 `NO_*` token 都按住，逐个映射后用 `+` 连接；`ctrl`/`control`/`alt`/`shift`/`win` 显示为 `Ctrl`/`Alt`/`Shift`/`Win`；任何 `NO_*` 约束标记丢弃。
  - 鼠标键：`LBUTTON`/`RBUTTON`/`MBUTTON`/`XBUTTON1`/`XBUTTON2`，带不带 `VK_` 均可。
  - Xbox 手柄：`XB_A`..`XB_GUIDE`、`XB_DPAD_*`、`XB_*_TRIGGER`/`SHOULDER`/`THUMB`；
    `XB1_`..`XB4_` 前缀表示指定手柄。
  - `Back = ...`：cycle 的反向键，归类不变，但显示时标注反向。
- 显示归一化：
  - 方向键 → `↑↓←→`；`NUMPADn` → `小键盘 n`；鼠标键 → `左键/右键/中键/侧键1/侧键2`。
  - 常见键名（F1-F24、Space、Tab、Enter、Esc、PgUp/PgDn、OEM 标点等）转可读名称；
    未识别的键名保留原名，未识别的十六进制码显示 `0xNN`。
  - 单字母键转大写；其余保持原样；多个 token 用 `+` 连接。
- 顺序：ini 文件按相对路径 `casefold()` 排序；文件内按出现顺序，同一段内 `key` 在前、`back` 在后；不跨文件去重。
- 解析按需触发，只读；不修改 `Mod` / `Snapshot` / scanner。

## 4. 界面

- `ModsScreen` 增加 `m` 绑定（描述「快捷键」），打开 `HotkeysScreen`。
- 弹窗：
  - 顶部：`<mod 展示名> · 已启用/已禁用 · N 个快捷键`（N 为行数）。
  - 禁用 mod：顶部黄字「该 mod 已禁用，以下快捷键在游戏中不会生效。」
  - 可滚动单列表；组标题 `切换 · N 项` / `长按 · N 项` / `其他 · N 项`，空组省略。
  - 每行三列：按键（加粗黄）、ini 段落名、来源文件（相对 mod 根目录，淡色，过长省略）。
  - 同一段落有多个 `key`/`back` 时显示多行；`back` 行的段落名后加 ` · 反向`。
  - 无快捷键：`该 mod 没有 ini 文件` 或 `该 mod 的 ini 里没有声明 [Key...] 快捷键`。
  - `↑↓` / `PgUp` / `PgDn` 滚动；`Esc` 或 `m` 关闭。
- mod 列表详情栏追加「快捷键：按 m 查看」。

## 5. 失败处理

- 单个 ini 读取失败：跳过该文件并写 warning 日志，其余文件照常展示。
- mod 目录不存在：返回空列表，弹窗显示空状态。
- 无 ini 或无 `[Key...]`：空状态，不报错。
- 禁用 mod：仍解析并展示，但必须显示不会生效的提示。

## 6. 验收标准

1. 选中 `Aemeath - Sky Pixie` 按 `m`，弹窗显示 `切换` 组 49 个按键和 `长按` 组 1 个按键。
2. 选中 `达妮娅-红绳捆绑` 按 `m`，`切换`、`长按`、`其他` 三组都出现，鼠标内部键在 `其他` 中。
3. 含 `Key` + `Back` 的 mod 按 `m`，同一段显示正向和「反向」两行（例如 `KeySwap` 的 `Ctrl+→` 和 `Ctrl+←`）。
4. 同一段有多个 `Key` 行（如 `X` + `XB_X`）时，每个键各占一行。
5. `VK_` 省略（`RBUTTON`）、十六进制（`0x70`）、Xbox（`XB2_LEFT_TRIGGER`）都能显示为可读按键。
6. 禁用当前 mod 后按 `m`，列表照常显示且顶部有黄字提示。
7. 选中没有 `[Key...]` 的 mod 按 `m`，显示「没有声明」空状态，不报错。
8. 50+ 条按键时可用方向键/PgUp/PgDn 滚动到底部。
9. 弹窗内按 `Esc` 或 `m` 回到 mod 列表；开关功能不受影响。
10. `pytest` 全绿；`ruff check .`、`ruff format --check .` 无错误。
